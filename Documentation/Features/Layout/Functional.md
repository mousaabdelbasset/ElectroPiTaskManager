# Layout — Functional Documentation

## ما الذي تغير؟

- يعرض الشريط الجانبي ملف `public/assets/logo.png` الحقيقي مع الحفاظ على النسبة وبديل نصي مترجم.
- عناصر التنقل أصغر وأكثر تقاربًا مع بقاء ارتفاع التفاعل 44px.
- زر New Task يملأ العرض الداخلي للشريط وتبقى المسافة متساوية من الجانبين في LTR وRTL.
- أزيلت دائرة المستخدم من الـheader من غير إضافة بديل أو authentication.
- في الموبايل يظهر نفس الشعار داخل الـheader، ويظهر الشريط الجانبي فوق المحتوى عند فتح القائمة.

السلوك responsive واتجاه الصفحة يظلان تابعين للغة المختارة.
