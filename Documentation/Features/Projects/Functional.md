# Projects — Functional Documentation

## سلوك إنشاء المشروع في الواجهة

بعد نجاح إنشاء المشروع:

1. يظهر المشروع فورًا في صفحة Projects دون refresh يدوي.
2. تُغلق نافذة الإنشاء ويُعاد ضبط النموذج.
3. تظهر رسالة نجاح مترجمة.
4. إذا وصلت نفس القائمة لاحقًا من الـAPI، لا يُضاف المشروع مرتين.

## الغرض

Feature المشاريع تسمح بإنشاء مشروع، عرض المشاريع، عرض مشروع مع مهامه، تعديل بياناته، وحذفه عندما لا يحتوي على مهام.

المشروع يحتوي على:

- `id`: رقم ينشئه السيرفر.
- `name`: اسم إلزامي، بحد أقصى 150 حرفًا.
- `description`: وصف اختياري، بحد أقصى 1000 حرف.
- `createdAt`: تاريخ UTC ينشئه السيرفر ولا يرسله العميل.

لا يشترط النظام أن يكون اسم المشروع فريدًا.

## العمليات المتاحة

| العملية                 | Endpoint                              | النتيجة الناجحة        |
| ----------------------- | ------------------------------------- | ---------------------- |
| عرض كل المشاريع         | `GET /api/projects`                   | `200 OK` وقائمة مشاريع |
| عرض مشروع وتفاصيل مهامه | `GET /api/projects/{id}`              | `200 OK`               |
| إنشاء مشروع             | `POST /api/projects`                  | `201 Created`          |
| تعديل مشروع             | `PUT /api/projects/{id}`              | `204 No Content`       |
| حذف مشروع               | `DELETE /api/projects/{id}`           | `204 No Content`       |
| عرض مهام مشروع          | `GET /api/projects/{projectId}/tasks` | `200 OK`               |

## إنشاء مشروع

مثال request:

```json
{
  "name": "Website Redesign",
  "description": "Redesign the public website"
}
```

لا يقبل الـrequest حقلي `id` أو `createdAt`. السيرفر ينشئهما.

## قواعد العمل

- الاسم مطلوب ولا يمكن أن يكون فارغًا أو مسافات فقط.
- المشروع غير الموجود يعيد `404 Not Found`.
- رقم المشروع الأقل من أو المساوي للصفر يعيد `400 Bad Request`.
- حذف مشروع يحتوي على مهمة واحدة أو أكثر يعيد `409 Conflict`.
- يجب حذف مهام المشروع أولًا إذا كان المطلوب حذف المشروع.
- التواريخ والأرقام التي ينشئها السيرفر لا يمكن التحكم فيها من request الإنشاء أو التعديل.

## أمثلة أخطاء

- اسم مفقود أو أطول من 150 حرفًا: `400`.
- مشروع برقم غير موجود: `404`.
- حذف مشروع يحتوي على مهام: `409`.

كل خطأ يُعاد بصيغة `ProblemDetails` ويحتوي على `traceId` للمساعدة في تتبع المشكلة.
